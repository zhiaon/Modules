# Surge域名规则采集器 · 0.1.0

本地收集到达普通 SCRIPT 规则、且 Surge 能识别主机名的连接，供用户预览、复制、导出分流规则。无需服务器、第三方 API、MITM 或 CA；不是 DNS 日志或完整 HTTP 历史。

## 远程订阅

模块：
https://raw.githubusercontent.com/zhiaon/Modules/main/DomainCollector.sgmodule

在 Surge 以 URL 安装模块，启用 **Surge域名规则采集器**，并核实脚本功能和规则模式已开启。脚本路径全部为本仓库 main 分支的 HTTPS raw URL，更新间隔 86400 秒。模块不替你切换全局开关。

**已有本地旧版的用户不要同时启用两份。** 名称变更不等于已完成本机迁移；本发布不安装远程模块、不修改已有启用状态。先确认旧模块停用与新模块启用的安全切换安排，再自行迁移。内部文件名、`DomainCollectorData` 存储键和 API 保持不变；无须为改名清空数据。

核实 `SCRIPT,DC采集,DIRECT` 是第一条普通规则；DIRECT 仅是语法占位，脚本始终返回 `matched:false`，不会选中它。前置规则、预匹配、临时规则、绕过 Surge 或 IP-only 连接仍可能缺采，不保证捕获所有连接。

## 本机管理

进入 Surge 的 **Surge域名规则采集器** 面板，点刷新，再打开 Surge 发出的通知。地址 `http://domain-collector.invalid/` 由本机脚本提供，不是公网网站，必须使用 HTTP。直接输入地址先显示锁定页。

面板仅自动读取轻量 root 摘要；刷新按钮签发一小时有效的随机访问凭证，取代上一份。通知 URL 凭证位于 fragment，页面读取后移除，只保留于页面内存；刷新页面后重新授权。不要分享带凭证的链接，不要把管理入口反代到公网。

概览首次只读摘要；域名、规则、设置页按需加载完整快照。可搜索、分页、排序、多选删除、调整条数上限和排除列表。删除需确认，全清还需输入 `CLEAR`；排除不追溯删除旧记录。

规则生成支持 DOMAIN / DOMAIN-SUFFIX、策略选择、分组、重复与冲突检查、复制和导出。DOMAIN-SUFFIX 使用所选完整域名，不扩大到父域；策略名必须存在于目标配置。输出仅是规则片段，不自动写入 Surge 配置。

## 数据与隐私

只保存规范化 ASCII 主机名、协议、时间及持久化采样计数和必要管理元数据。不收集流量 URL、Cookie、请求体、来源地址、进程或设备标识；无域名上传接口。管理适配器仅读取明确本地管理请求所需的路径、Origin、控制头和主动提交的 JSON。

默认上限 5000，最多 10000；root ≤160 KiB UTF-8，48 个分片各 ≤64 KiB / 256 条，通用单值硬守卫 3.5 MiB。超限拒收，不逐出旧域名。次数是 60 秒合并窗口下的持久化采样下界，不是精确连接数；并发与存储失败可能漏记。未知版本/损坏数据不做破坏性迁移。
