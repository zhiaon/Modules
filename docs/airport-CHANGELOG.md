# 机场流量 V1.0 · 更新日志

## V1.0（2026-11-05）

首个公开版。在 Surge 策略页显示最多 6 个机场的流量用量。

- 六个机场各占一组参数：机场name / 订阅URL / 重置日，一一配对，不用哪组保持占位文字即可
- 每个机场按自己的重置日算下次清零日期，填 31 遇到小月自动按当月最后一天
- 显示总流量、已消耗、剩余、环形进度条、↑上行 / ↓下行、到期日
- 多机场自动切紧凑排版（3 行/机场），末尾给合计
- 数据直读订阅响应头 `subscription-userinfo`，拿不到时退化解析 body JSON
- 拉取失败优先显示上次缓存并标黄，不白屏
- 本机请求，订阅链接与 token 只存在本机模块参数，不经任何第三方中转
- 状态色：<90% 绿、≥90% 黄、≥100% 红、未配置灰

参数（共 18 格，六组三格）：

| 参数 | 说明 |
|---|---|
| 机场name1~6 | 面板显示的名字，例：花云 |
| 订阅URL1~6 | 完整 https 订阅链接，带 ?token= 的部分全部照抄 |
| 重置日1~6 | 该机场每月几号清零，1-31 |
