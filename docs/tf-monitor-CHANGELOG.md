# CHANGELOG

## 1.0.1 — 2026-11-26

- 修复每分钟启动导致的频繁运行警告，改为Surge原生cron分钟步进；默认10分钟，每小时6次。
- 参数范围改为1–59；推荐10/12/15/20/30，1–5仍有警告风险，非60因子跨小时不保证等间隔。
- 升级需更新模块本身，并将保留的旧5分钟参数改为10；仅更新JS不能修复旧cron。
- 保留状态缓存、去重、双并发；新JS兼容旧参数格式。Node82/82与原生JSC隔离回归通过。

## 1.0.0 — 2026-11-26

- 首次发布 TestFlight 多链接名额监控模块及脚本，最多 10 个链接独立节流、状态去重，默认检查间隔 5 分钟。
- 仅 GET 公开邀请页；未知状态不通知，不自动报名，不强制唤醒。
- JS 与已安装源码逐字节一致；模块仅将本地脚本路径改为仓库 raw URL，并加入 `script-update-interval=86400`。
- 保留模块名称、其他字段与 `tf_links:-,interval_minutes:5` 默认值；不包含活动参数或缓存数据。
- 现有 Node 离线回归测试 63/63 通过。
